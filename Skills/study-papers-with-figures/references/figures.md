# 原图与覆盖规则

## 清单

创建项目清单，字段示例：

```json
{"source":"paper.pdf","scope":"main paper and appendix","figures":[{"id":"Fig. 5","source_pages":[11],"title":"density-field snapshots","panels_expected":["a","b","c","d","e","f","g","h"],"panels_verified":[],"lecture":"density-field","exports":[],"crop_rects":[],"visual_verified":false,"status":"pending"}]}
```

从原文视觉核对得到预期子图，不猜测编号序列。中文解释保留源标签，如 Fig. 5(a)。无编号图赋内部 ID 并明确标为无编号；记录跨页续图、附录图、未提供的补充材料。表格和算法单独统计。

## 裁切与解释

1. 用全文与图注定位，检查整页渲染。双栏、扫描件、跨页图手工补全清单。
2. 用图形、图片和文字标签的联合边界确定裁切。单独写中文图注，出处用 PDF 物理页码；有不同印刷页码时同时注明。
3. 保留所有子图、图例、色条、坐标轴、刻度、实验数据。不要只提取 image object，否则会漏矢量文字和箭头。
4. 默认用 `show_pdf_page` 导出矢量 PDF。旋转和 CropBox 页面先核对输出，不能照搬其他阅读器的旋转坐标；必要时忠实高分辨率栅格裁切。
5. 增加 DPI 不会创造原文件没有的细节。不能生成虚假的高清实验图或补写无法辨认的数据。
6. 密集多子图先展示全图，再两列分组放大或单图细读，保留比较关系；不要缩正文以塞入全图。
7. 中文说明写清对象/图例/轴与单位、读图方向、输入操作与输出、控制公式、实验配置和证据范围。

区分同篇论文的不同配置：仅密度与完整目标、CG 与 Nesterov、有无预条件、全局布局与合法化后。横轴迭代数不等于运行时间；双纵轴不直接比较数值大小。

## 字体保真与合订本

从独立 PDF 与封面重新构建，先算真实页数再写索引。重复运行不追加相同封面内容。尽量在 LaTeX 端统一页码；合并后需要覆盖旧页码时，在已核对的页脚数字区域画白色遮罩，再写新页码。

避免在包含原图的整页运行全局 redaction 或文本删改：重写嵌入字体可能让原图希腊字母消失。若必须删改，逐图对照源图检查全部符号，而非只检查中文正文。

## 覆盖声明

交付给出已覆盖 X/Y 幅编号图及已核对子图范围，注明无编号图、附录、补充材料、表格和伪代码的状态。没有核对清单时不可说全部覆盖。
