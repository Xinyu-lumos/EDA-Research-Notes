# 论文精读与图解笔记

以用户指定的当前论文为依据，将慢节奏中文教学、原图研读和学术讲义结合。遵从当前用户要求，保留英文术语、准确公式、论文图号与页码。不要将某篇论文的七天安排、图数量或实验结论套到其他论文。

## 1. 确定资料与进度

- 读取论文全文，确认标题、版本、PDF 物理页码、研究对象与贡献。不要把稿件 DOI、年份、卷期占位符当出版信息。
- 修改已有笔记时，读取当前版本和源文件；保留用户删除的段落，不在修订中重新加入。
- 有多个候选论文时先澄清；资料已明确时直接推进。资料缺失时请用户提供 PDF 或链接。
- 默认按天推进，每天解决一组前置知识依赖，第一天建立问题地图。按难度决定天数，不固定七天。“完成剩余天”时交付剩余独立讲义和合订本，不停在计划。
- PDF 工作使用可用的 PDF 技能；文件保存遵守环境规则。EDA 主题结合可用的 `study-eda-papers` 技能。

## 2. 建立原图覆盖清单

读取 [原图与覆盖规则](references/figures.md)。运行 `scripts/paper_figures.py inventory PAPER.pdf --out inventory.json` 找候选图注，再逐页视觉核对。脚本不能证明完整覆盖。

创建项目内 `figure-coverage.json`，记录每个原图编号、源页码、标题、预期子图标签、已核对子图、讲义章节、裁切范围、导出路径、清晰度和完成状态。记录无编号图、跨页图及补充材料；表格和算法另列。

- 按本次学习范围引用原图；完成整篇且要求全部图片时核对所有编号图及子图，说明无编号图、附录和补充材料的范围。
- 不把 PDF 嵌入图片对象数或检索候选数当原图总数。
- 直接裁切原图，保留全部子图、坐标轴、图例、色条和指标，优先保留矢量元素。密集图先放全图，再按需要分组放大。
- 每图配中文图注、出处和读图说明：对象与图例 → 阅读方向 → 状态变化 → 对应公式 → 实验配置与限制。
- 用户提供论文按其学习需求处理；外部获取原图遵守引用、许可与使用限制。
- 生成原图覆盖索引和书签。只有所有清单项已核对才声称全部覆盖；否则列明缺项及原因。

## 3. 写可跟得上的讲义

读取 [教学与学术排版](references/teaching-and-layout.md)，从 `assets/academic-notes.tex` 建立可编辑讲义。

- 每节只推进一个概念瓶颈，先定义对象、变量和约束，再讲公式。
- 按“任务 → 符号与单位 → 因果解释 → 分步推导 → 最小数值例子 → 算法位置”解释公式。梯度说明对谁求导、符号和实际移动方向。
- 区分原文明示、教学补推、教学例子和跨论文推断。原文公式/图号与讲义编号分别管理。
- 中文矢量图补充原图：模型对应、布局前后、场与梯度、曲线、坐标更新、算法反馈。用标准绘图/TikZ/SVG制作精确图，不用生成式图像绘制数学或数据图。
- 核对实验配置、基线、硬件、计时口径、测量阶段和消融证据；不把优化目标改善当布线或时序证明。
- 不默认添加自测题。根据当前用户要求调整，不把笔记变成原文翻译或只有概括。

## 4. 编译与交付

- 用 XeLaTeX/LuaLaTeX 编译中文 PDF，统一宋体风格正文、数学字体、蓝灰配色、标题层级、图注和页眉页脚。不为固定页数压缩字号。
- 先发现中文字体，必要时提供项目级 `paper-fonts.tex`；确认正文、粗体、图中文字可显示。
- 检查 missing character、overfull box、缺图和引用。渲染所有新改页，核对中文、希腊字母、负号、小标注、箭头、裁切与分页。
- 示例裁切：`scripts/paper_figures.py crop PAPER.pdf --page 7 --rect 108 99 528 300 --out figures/fig05.pdf`。页码从 1 开始，坐标为 PDF 点。先确认范围，不沿用其他论文参数。
- 合订本从独立讲义重建，按真实页数计算目录和书签，不反复追加索引。连续页码处理保留原图字体，见原图规则。
- 完成后记录真实页数、图覆盖数和限制，保存 PDF 与可编辑 LaTeX 源文件，遵守当前环境的文件保存规则。仅在用户授权时归档 Notion/GitHub，成功后才声称同步。
- 最终简述新内容和检查结果，提供笔记链接，不每轮要求用户确认排版细节。
