# FPGA 可布线性驱动宏布局

## 原论文

**Routability-Driven Macro Placement Engine for Modern FPGAs with Complex Cascade Shape and Region Constraints**  
Hao Gu, Jian Gu, Keyu Peng, Jianli Chen, Jun Yang, Ziran Zhu.

IEEE Transactions on Computer-Aided Design of Integrated Circuits and Systems, 2025.  
DOI: [10.1109/TCAD.2025.3562952](https://doi.org/10.1109/TCAD.2025.3562952)

[原论文 PDF（14 页）](Paper.pdf) · [Notion 条目](https://app.notion.com/p/3e7106e3498e81b09661d049d00b4bf1)

版本：作者接受稿，首页卷期为占位符；论文注明早期版本发表于 DAC 2024。

## 研究问题与方法

在复杂级联形状和区域约束下优化 FPGA 宏布局的可布线性。方法结合带拥塞预测的混合尺寸全局布局、基于 ILP 的级联形状合法化、匹配式宏合法化与可布线性驱动的详细宏布局。
