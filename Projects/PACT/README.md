## 阅读方式

GitHub 文件页展示 HTML 源码。下载本目录的 7 份 HTML 文件到同一个文件夹，再用浏览器打开 Day1；各天之间的导航可直接使用。每份笔记的样式与 SVG 图示均已内嵌。

笔记中的 `../FDAgents/`、`../VivadoMCP/`、`../RapidWrightMCP/` 等源码路径引用 PACT 原项目，本目录仅归档学习笔记；查看源码时请对照原项目目录。

HTML 文件保留原始内容与文件名。笔记所标注的核对日期为 2026-09-30。
